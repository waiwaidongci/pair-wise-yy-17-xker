# 凝结水样链与沉积速率复核台

洞穴凝结水采样链登记、送检录入与沉积速率复核的小系统，规则、存储、页面三层分离。

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912 ，数据保存在 `data/db.json`。

## 分层

- `rules/chemistry.js`：规则引擎（纯函数，无 I/O）。顶空一成、校准半小时、
  读数偏离容差、速率负增长、降幅两成、封条比对等阈值与判定全部在此。
- `project.config.js`：业务声明（样点 / 样单字段、状态、动作、统计口径）。
- `server.js`：存储层。JSON 文件持久化；写操作经单条 Promise 链串行化，
  保证并发下瓶号占用与状态流转安全。
- `public/`：页面层（原生 HTML/CSS/JS），只展示服务端算好的结论，不做判定。

## 业务规则

- 一瓶号在归还前只能有一份未结束样单（状态：待送检 / 复核中 / 合格）。
  重复登记或并发提交沿用首次结果，服务端按幂等键与瓶号双重去重。
- 登记时自动判定：顶空 >10%、仪器校准距今 >30 分钟、现场读数超出样点容差，
  任一命中即转「待重采」，该单结束、瓶号释放。
- 送检必须换人：录入人不得等于采集人；录入封条号与沉积质量后自动计算
  暴露天数与沉积速率（质量 / 天数）。速率负增长、较上一份（无则基准速率）
  降幅 >20% 或封条号不符，转「复核中」，否则「合格」。
- 复核人给出「合格 / 待重采」结案；合格样单执行瓶号归还后归档，瓶号可复用。
- 样点基准（基准读数 / 基准速率 / 容差）、样单沉积质量或采集时刻变更时，
  相关样单结论自动失效重算，旧结论快照写入「旧版留档」，人工复核结论同步失效。
- 列表、统计看板与履历均来自同一份存储，任意操作后整体刷新保持一致。
